🚀 EduFilter Demo – Quick Start
Install the Chrome Extension:

Go to chrome://extensions

Enable "Developer mode"

Click "Load unpacked" and select the /extension folder

Test Web Filtering:

Visit a site that contains blocked keywords like porn or proxy

The page should be blocked by EduFilter

Use the Admin Dashboard:

Open the dashboard at: https://sudo-mu.vercel.app/

Add more blocked keywords

Click “Enable Uninstall” to remotely disable the extension

Extension Will Prompt:

Once uninstall is enabled, the student will see a popup:

“Admin has disabled EduFilter. Please uninstall the extension.”
